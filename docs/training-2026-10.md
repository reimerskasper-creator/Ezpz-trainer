# Home schedule and Train optimization

Home now shows the next three actual scheduled, uncompleted workouts in chronological order, with 50px thumbnail covers from the same program metadata used in the chooser. A Next 7 days view includes workouts, rest days and unplanned days. Selecting a blank day opens the planner on that date. Changing Home views never writes a plan. With no schedule, the selected workout is explicitly unscheduled and remaining rows invite planning rather than inventing dates.

Train preserves all session IDs, prescriptions, set field keys, storage keys and standard finish/history behavior. The header is more compact and presents equipment, duration and context. Focus view opens one exercise at a time; All exercises expands the session. Both retain every set input in the DOM and save on input, so collapsing, navigating and switching views cannot drop results. Exercise jump chips, per-exercise progress, Next exercise and Continue workout reduce scrolling. Resume defaults to the first exercise without all valid sets complete. Explicit exercise navigation is remembered per workout/variant for the current page session; the focus/all preference persists.

Use previous only fills blank results from compatible completed sets in the latest exercise performance; empty logs no longer hide older completed performance. Repeat entered set copies the closest earlier entered set into the next blank, unchecked set while preserving an entered target weight. Both actions require explicit clicks and never mark a set completed. Weight inputs accept fractional loads.

Progress counts a checked set only when its result is positive. Empty checked sets show inline feedback and count as incomplete. Finish retains the existing validation and now rejects invalid weights. The intended confirmation for entered but unchecked sets previously examined already-blanked data; it now checks the original fields before clearing a finished draft. Dismissing confirmation leaves entries intact.

A sticky rest timer offers 30/60/90/120-second presets plus each exercise's rest target, pause/resume and clear. Automatic start after a valid completed set is opt-in. State stores a deadline, so reloads and background time do not reset the countdown. No sound, notifications, external services or fabricated training duration are introduced. The timer clears when the workout is saved.

New state fields: trainingView, autoRest, restTimer. Restoration preserves them; readers treat unknown view values as focus, automatic rest is enabled only by true, and invalid timer objects are ignored. Existing workout drafts, food, plans and backup data remain intact. No approved food functions, recipes, photos, macros, portions or styles are modified.

Verification adds tests/training.cjs for schedule ordering/covers, honest empty states, copy/repeat behavior, progress, focus/all modes and deadline timer state. Real Chromium coverage adds Home schedule views, result reuse, invalid-result correction, opt-in timer/pause/reload, focused navigation, view switching, unchecked-result confirmation and finished logs at 320/390/430px. Dedicated screenshots show Upcoming workouts, Train overview and Focused training.
