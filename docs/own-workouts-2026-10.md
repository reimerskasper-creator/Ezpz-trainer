# Own workouts

Create your own is a photo tile in the main workout chooser and planner. A simple form accepts a session name and arbitrary exercise names, sets and reps. Optional details contain cover/focus, experience, equipment, duration, time units, rest and per-side settings. Saved workouts can be started and resumed using the standard Train page. Save for later leaves the schedule and selected workout intact. Save & start selects the new workout without scheduling it. Planner saves target only the chosen date. Existing custom workouts remain compatible.

Validation covers free-text names, stored templates, destination-specific writes, rollback, backup compatibility and phone-sized browser flows. Approved recipes and built-in workout prescriptions remain unchanged.
