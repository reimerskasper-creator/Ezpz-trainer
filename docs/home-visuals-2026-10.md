# Home visual refresh
Visual hierarchy: brand/date → selected workout → nutrition → weekly consistency → upcoming workouts → weight/settings.

The Home-only stylesheet preserves the rest of the app. The ring uses existing calorie totals and goals: its arc caps at 100%, but its percentage and over-target label remain accurate. Native progress semantics remain available to assistive technology. Macro progress bars explicitly style Chromium and Firefox fills; original gray native appearance was visually unclear.

Weekly training-day numbers use the same Monday-through-Sunday dates and unique logged-day data as before. Existing upcoming-workout photos, schedule tabs, rest days and honest unscheduled states are unchanged. All navigation handlers and data keys are unchanged. No new metrics or fictitious completion data were introduced.

Verification: Home unit coverage for zero/over-goal calorie display and unchanged saved data; existing Home/Train/recipe suites; real Chromium at 320/390/430px; screenshots of the hero, nutrition, week and next-workout components.
