# Planner photo pickers

Replaced the long native workout and recipe selects in My plan with matching photo-card buttons and one native modal dialog. Short plan-length and portion selects remain. Workout browsing supports eleven photo categories, search across names/equipment/exercises, experience filters, saved custom sessions, and expandable exercise prescriptions. Rest, remove and build actions are explicit. Recipe browsing supports the same 49 approved photographs, name/ingredient search, meal-type filters, and per-serving calories and macros. A meal slot defaults to its corresponding type, while All permits any approved recipe.

The modal records its target date and meal slot when opened. Browsing, filtering, Escape, Close and backdrop dismissal never write to storage. Choosing a workout changes only workoutSchedule for that date, preserving the active workout and drafts. Choosing a new recipe uses one serving; choosing the same recipe preserves its existing portion. Explicit removal affects only the target day or slot. Planning never changes foodLog. If saving fails, the prior plan reference is restored and the dialog remains open.

The dialog has a fixed header, independently scrolling body, native focus trapping, labeled search, and focus restoration. The close control receives initial focus so opening it does not automatically summon the phone keyboard. No additional persisted state, recipe indices, nutrition reference data, photographs, workout prescriptions or approved food functions were changed.
