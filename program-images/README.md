# Workout program covers

Optimized 960 × 480 JPEGs generated with the built-in image-generation tool for EZPZ Fitness.

`docs/program-cover-mapping.json` assigns a relevant cover to every built-in workout choice. Category overview photographs remain unchanged. Related movements may share an asset across different categories; every program within one category has a distinct cover.

These are decorative program illustrations, not technique demonstrations or photographs of a user's workout. Individual exercise instruction imagery is unchanged.

Prompts and asset hashes are recorded in `docs/program-covers-2026-10.json`.
