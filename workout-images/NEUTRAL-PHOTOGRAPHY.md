# People-free workout photography

Category and program covers use the approved equipment-and-spaces direction: forest green, warm wood, natural daylight, no people. Each program keeps the same cover throughout Home, the chooser, planner, training and history. Every category has distinct program covers.

50 new images were generated with the built-in image generation tool and visually reviewed, then resized to 960 × 640 JPEGs for mobile delivery. Nine matching existing equipment images remain in use. See neutral-manifest.json for asset descriptions and cover assignments. These covers are editorial illustrations of a training setting, not exercise technique instructions.
