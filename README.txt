EZPZ Trainer v1 — free, local-first prototype.
To use as a mobile PWA, host the contents of this folder on an HTTPS static site (for example a free static hosting tier), then open the HTTPS URL in Chrome on Android and select Add to Home Screen / Install App.
Opening index.html directly from a file may not enable offline service workers or installation.
Data is stored in localStorage for the specific browser origin. Export JSON backups regularly. It is not encrypted, authenticated, or appropriate for sensitive client health records. Use anonymous client codes and confirm employer policies before real-world use.
